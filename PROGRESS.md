## Roadmap to a production bot (live orders, unattended)

Spec for the target: `ARCHITECTURE.md` (review of today's code and the ports-and-adapters design).
Everything above is a paper bot; the order path (dry run and live) was added in 0.11.0 and still needs the phases below before real money.
Order matters: a gate first (is there an edge?), then engineering foundations, then execution,
then operations, then a staged rollout. Phase 9b can run in parallel with 11 to 14 as long as the
forward test runs on a tagged, unchanged version.

- 16 Oct 2026, pivots now match TradingView (on branch `main`; this changes live and replay behaviour). The bot's pivots were 2 to 12 points off TradingView's Pivot Points Standard (Traditional): the formulas were right, the previous session's low and close were not. TradingView's daily bar includes the 09:09 pre-open trade in the low (22671.0, not 22675.0) and closes on the exchange's closing price (22984.8, not the last candle's 22998.8).
